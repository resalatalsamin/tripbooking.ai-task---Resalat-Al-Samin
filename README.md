# TripBooking.AI Task

This project is a frontend implementation of a travel booking UI based on the provided design. The goal was to build a clean, responsive, and component-based React application while maintaining design accuracy.

## 🚀 Setup Instructions

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/resalatalsamin/tripbooking.ai-task---Resalat-Al-Samin.git

   ```

2. Navigate into the project folder:
   cd tripbooking.ai-task---Resalat-Al-Samin

3. Install dependencies:
   npm install

4. Run the development server:
   npm run dev

- Assumptions

While building this project, I made a few practical assumptions:

The design provided in Figma represents a static frontend, so backend/API integration was not included.
Some spacing values (like decimals in pixels) were approximated using Tailwind’s closest available utilities.
Images and icons were used as local assets for consistency and performance.
Carousel behavior was implemented using a modern library (Swiper) to better match multi-card layouts.
Responsiveness was handled using a mobile-first approach based on common breakpoints.

- Features Implemented

Fully responsive layout (mobile, tablet, desktop)
Reusable component structure (e.g., TourCard, Button, Navbar, Footer)
Feature-based folder organization for scalability
Swiper-based carousel for multi-card sliding
Clean UI matching the provided design as closely as possible
Tailwind CSS + DaisyUI for styling
Custom theme colors (primary & secondary)
React Router setup for navigation
Optimized and structured asset usage
